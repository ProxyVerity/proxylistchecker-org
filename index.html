Put a proxy checker on your site

One script tag. Your visitors paste a list of proxies, each one is tested against HTTP, SOCKS4 and SOCKS5, and the results come back on a page they can bookmark or share. Nothing runs on your server.

Install it in about thirty seconds

Paste this where you want the checker to appear. That is the whole installation — there is no build step, no package, no API key.

What it costs you

Nothing, and there is no catch worth hiding. The widget asks for exactly one thing: a small line under it reading Proxy checker by ProxyVerity, with a link. Keeping that line visible is the condition of use.

We say this plainly because you will see it the moment you paste the tag, and a surprise is a worse start than a sentence.

Who puts it up

Sites that publish proxy lists, so readers can check a list before trusting it. Scraping and automation blogs, where a working tool beats another screenshot. Webmaster tool collections, which is simply what the thing is.

If your readers already paste proxies into something, they may as well do it without leaving your page.

It can look like your site, not ours

Colours, corner radius and typeface are attributes on the tag. The palette carries through to the results page too, so nothing reverts to our styling at the moment your visitor is reading their results.

Colours are checked on our side; anything that is not a plain hex value quietly falls back to the theme's own, because these end up inside a stylesheet. The full reference, including the batching options for long lists, is in the widget documentation, and there is a visual builder with every option and a live preview.

Prefer not to embed anything?

Then just use the hosted one. The ProxyVerity proxy checker is the same engine without the script tag, and the free proxy list is a continuously re-checked table you can filter by country, protocol and anonymity level — useful for seeing what a live list actually looks like.

On WordPress? There is a plugin

Search for ProxyVerity Proxy Checker under Plugins → Add New, or get it from the WordPress plugin directory. Then drop in the Proxy Checker block, or the [proxyverity_checker] shortcode, and set the colours site-wide under Settings.

The plugin adds no database tables, no cron jobs and no server-side requests. It writes the same tag as above and the hosted checker does the rest — which also means fixes reach you without you updating anything.

Also available as a package

If you build pages rather than paste into them: npm install proxyverity-widget or composer require proxyverity/proxy-checker-widget. Both are thin wrappers that build the same tag; neither carries a copy of the checker. Source and mirrors: GitHub.

proxylistchecker.org is run by the team behind ProxyVerity, which is where the checker itself lives. We mention it rather than pretending otherwise.
